What is AWR?

RL-Trained Policy

A PPO agent trained from scratch via curriculum learning in a custom Gymnasium warehouse simulation. 92% navigation accuracy across six difficulty levels — zero collisions.

PPO v6.2Stable-Baselines3Gymnasium

Dual Sensor Architecture

Two fully decoupled pipelines: a 360° LiDAR for spatial navigation and obstacle avoidance, and a Pi Camera + Tiny-YOLO for real-time box and SKU identification. Both run in parallel — neither blocks the other.

360° LiDARPi CameraParallel Pipelines

Safety-First Design

A deterministic Safety Guard Node overrides RL commands whenever LiDAR-derived braking distance constraints are violated — guaranteeing zero collisions regardless of policy edge cases.
